# Port Scanner

A simple Python port scanner I built while learning about **sockets and network connections**.

## What it does

This program:

- Asks for a target IP address
- Checks a range of ports
- Attempts to connect to each port
- Tells you whether the connection succeeded or failed

## Requirements

- Python 3.x
- No external libraries required

## How to run

```bash
python port_scanner.py
```

Then enter an IP address when the program asks for one.

## Important

Only scan devices and networks that you own or have permission to test.
